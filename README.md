## How to read the answers

There is no build tooling or test suite here. This is a written assessment,
not a running application. Each `README.md` under `part-*/` is a
self-contained answer meant to be read on its own.

Every answer is written in plain, simple English. The reasoning and the
engineering trade-offs are kept at full depth — only the wording is made
easy to follow, since a reviewer may be skimming under time pressure or may
not share the author's first language.
